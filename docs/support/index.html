Zoomdle is a daily game: guess the photo as a tight crop zooms out to the full image. You have six guesses per puzzle.

Restore Zoomdle Plus

If you already subscribe, open Settings in Zoomdle and tap Restore Purchases, or use Restore on the Archive paywall. Use the same Apple ID you used to subscribe.

To change or cancel Zoomdle Plus, go to iOS Settings → [your name] → Subscriptions.

Something isn’t working

Please open a GitHub issue with the iOS version, what you tapped, and what you expected.
